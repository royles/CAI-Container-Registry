Image lifecycle (OCI best practice)

  1. Create — empty repository or first docker push / replicate.
  2. Update — push or replicate the same tag again (new manifest digest; old blobs stay until GC).
  3. Retire — delete individual tags (below) or the whole repository.
  4. Reclaim — run garbage collection to remove unreferenced blob files.

Use the lock icon to protect production repositories from rename and delete. Push and pull are not blocked.
